# 松江 介護事務ナビ

松江市の介護法人本部向けの公開情報サイト（確認用初稿）。

## 内容

- 特養（従来型・ユニット型）、訪問介護、通常の通所介護、居宅介護支援の人員基準一覧
- 介護保険最新情報10件の概要表と公式PDFへのリンク
- 松江市の認定・申請手続き、サービス解説

`dist/index.html` がサイト本体です。JavaScriptに依存せずメニューと本文を表示し、iPad幅では人員基準の表をカード形式で表示します。iPad実機での検証は未実施です。

## Cloudflare Pagesで公開

1. Cloudflareの「Workers & Pages」からアプリケーションを作成し、Pagesで既存のGitリポジトリを取り込みます。
2. GitHubの `AlexaHelth/matsue-care-navi` を選択します。
3. 以下を設定してデプロイします。

| 項目 | 設定 |
| --- | --- |
| フレームワーク | None（なし） |
| 本番ブランチ | main |
| ビルドコマンド | exit 0 |
| ビルド出力ディレクトリ | dist |

環境変数の設定は不要です。公開URLはデプロイ成功後にCloudflareが発行します。連携後はmainへの更新で再デプロイされます。

公式手順: https://developers.cloudflare.com/pages/framework-guides/deploy-anything/

## 情報の更新と確認

AIが初稿を作成し、担当者が原本と照合したうえでHTMLと確認日を更新します。情報の自動収集・自動更新は実装していません。

現在は国の基準の要約を掲載しています。松江市条例・解釈通知との照合は未完了のため、確認用初稿の表示と検索エンジン向けnoindexを付けています。確認が終わるまではこの表示を維持してください。

PDFは公式サイトの原本へリンクし、開いたブラウザの保存操作でダウンロードします。
